# 设计规范：配色 / 排版 / 层次

科研图的基本设计原则。出图渲染时必须遵守。

## 配色

- **使用专业学术配色方案**，不要随意取色。推荐（按优先级）：
  - **Okabe-Ito 色盲友好**色板（学术标配）
    - 蓝 #0072B2、橙 #E69F00、绿 #009E73、红 #D55E00、青 #56B4E9、紫 #CC79A7、黄 #F0E442、灰 #999999
  - Science/Nature 风格：克制、低饱和、大块面
- **主色 ≤ 3 种** + 中性灰。辅助色用于强调（高亮单个关键元素才用对比色）。
- **语义化用色**：红=危险/异常/阳性，绿=安全/正常/对照，蓝=主流程/操作。
- 背景默认纯白（期刊印刷要求），避免渐变与阴影。
- 详细色板参考 `academic-figure-generator` 项目沉淀的 8 套学术配色。

## 排版与字体

- 无衬线字体（Arial / Helvetica / 思源黑体），**图内文字 ≥ 10px**。
- 层级：图标题 > 模块标注 > 内部说明文字。
- 对齐：元素对齐、间距均匀、留白充足，避免拥挤。
- 箭头与连线：粗细一致，箭头方向清晰，交叉尽量少。

## 层次与强调

- **视觉层次**：读者第一眼看到最重要的元素。尺寸/颜色/位置制造层级。
- **分组**：用同色背景/方框把相关模块圈起来，标注组名。
- 一个图**只表达一个核心信息**；信息过多则拆成子图 a/b/c。

## 期刊适配

- 矢量输出（SVG/EMF），分辨率无限。
- 单栏图宽约 8.5cm，双栏约 17.5cm，SVG viewBox 按此比例设计。
- 线宽 ≥ 1pt，保证缩小印刷仍清晰。

## 自检清单（出图后）

- [ ] 用色 ≤ 3 主色 + 灰
- [ ] 文字全部 ≥10px 且无衬线
- [ ] 箭头方向清晰、连线无交叉混乱
- [ ] 只有一个核心信息，层次分明
- [ ] 背景纯白、无无意义渐变阴影
