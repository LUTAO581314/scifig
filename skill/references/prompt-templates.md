# 提示词模板

供 LLM 拆解与出图使用的标准提示词骨架。用国内模型（OpenAI 兼容接口）调用。

## 一、拆解提示词（阶段2）

```
你是学术论文分析专家。请拆解以下论文，产出"可作图信息"的结构化结果。

【论文】
{已解析的论文文本(markdown)}

【用户作图需求】
{用户需求描述}

请按步骤输出：
1. 论文类型分类（用 paper-types.md 的 7 类，给置信度+证据）
2. 可作图信息清单：每条标注类型(流程/机制/架构/对比/结构/数据)与对应原文位置
3. 推荐图清单（用 figure-types.md 的 11 种，给 1-3 个候选）
4. figure_spec JSON（供渲染阶段使用）

要求：忠实原文，不臆造；标注每条的来源位置；不确定的标 low-conf 让我复核。
```

## 二、确认展示模板（阶段2 确认闸门）

把 structured JSON 转成给人看的简明文本给用户确认：

```
📄 拆解结果
论文类型：机制研究（置信度 0.9）
可作图信息：
  1. [机制] 药物-受体-下游信号通路（来源：图1/方法4.2）
  2. [架构] 检测系统总体框架（来源：图2/引言）
  3. [流程] 实验设计步骤（来源：方法3.1）
推荐图：机制图 + 架构图
请问：(a)确认按此出图 (b)增删改哪个部分 (c)调整图类型
```

## 三、出图提示词/规则（阶段3）

分两种渲染路径：

### A. 文本 DSL 路径（首期 MVP）
把 `figure_spec` 交给 `render_svg`/`render_emf` 工具，用**声明式描述**渲染：
- 模块（圆角矩形+文字）
- 连线/箭头（起点→终点+标签）
- 分组（分组名+颜色）
- 布局方向（LR/TB）

用编程方式生成 SVG/EMF，遵循 design-theory.md。

### B. 图标/机制图增强路径（可选）
对需要"细胞/分子/蛋白"等拟物图元的机制图：
1. 先从 research-figure-library / Bioicons / Servier Medical Art 匹配图标素材
2. 再用矢量组合，避免直接用 AI 图像生成（难编辑、易失真）

## 输出 JSON schema（figure_spec）

```json
{
  "figure_id": "fig1",
  "title": "图1 系统整体框架",
  "direction": "LR",
  "groups": [{"name": "输入层", "color": "blues"}],
  "nodes": [{"id": "n1", "label": "数据预处理", "group": "输入层"}],
  "edges": [{"from": "n1", "to": "n2", "label": "特征" }],
  "caption": "图注建议文字(含方法简述与引用位置)"
}
```
