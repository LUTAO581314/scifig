# 论文类型分类决策树

拆解论文的第一步：判断论文属于哪一类，因为**不同论文类型 → 不同图示方式**。
此表用于 LLM 拆解阶段归类，也用同一判断在出图时选择视觉规范。

## 7 类论文类型

| # | 类型 | 判断特征 | 最常配的图类型（见 figure-types.md） |
|---|------|---------|-------------------------------------|
| 1 | **方法/方案 Method** | "我们提出/设计了一种方法/系统/算法"，强调怎么做的 | 流程图、架构图、pipeline |
| 2 | **机制/机理 Mechanism** | "揭示了…机制/通路/原理"，强调因果与相互作用 | 机制图、示意图、多图层叠 |
| 3 | **评测/分析 Evaluation** | "我们评估/比较/分析"，强调实验与对比 | 对比矩阵、数据图、流程图(实验设计) |
| 4 | **综述 Review** | 大量引用，罗列已有成果/分类 | 分类树、对比表、时间线 |
| 5 | **理论 Theory** | 定理/推导/证明为主 | 结构图、推导图、TikZ |
| 6 | **工程/系统 System** | 硬件/软件/设备系统，强调部件与连接 | 架构图、组件图、系统框图 |
| 7 | **数据/资源 Dataset & Benchmark** | 提供数据集/工具，强调规模与内容 | 数据分布图、示意图、流程(构建流程) |

## 判定步骤

1. 读标题+摘要：抓"提出/揭示/评估/综述"等信号词
2. 读方法首段、结论段确认
3. 一个"uncertain"/置信度<0.8 时，在确认闸门中请用户复核

## 输出约定

拆解时输出：
```json
{ "paper_type": "mechanism", "confidence": 0.9, "evidence": "摘要出现'揭示了…机制'" }
```
